FAQ

Frequently asked questions

What is JARVIS?

JARVIS (Just A Rather Very Intelligent System) is an open-source AI desktop assistant for macOS. It works with 12+ AI providers, supports voice interaction, and includes a multi-agent workforce system. Think of it as your personal AI command center — inspired by Iron Man's JARVIS.

Is JARVIS free?

JARVIS itself is completely free and open source (MIT license). The AI providers you use may have their own pricing — but many offer free tiers (Gemini, Groq, Mistral, OpenRouter, Together, Fireworks) and Ollama lets you run models locally for free with no API key.

Which macOS versions are supported?

JARVIS requires macOS 12.0 (Monterey) or later. Both Apple Silicon (M1/M2/M3/M4) and Intel Macs are supported with separate builds.

Will Windows and Linux be supported?

Yes — Windows and Linux support is coming soon. The app is built with Tauri, which supports all three platforms. We're starting with macOS and expanding based on community demand.

Is my data private?

Yes. JARVIS is local-first — all your data (conversations, memory, agent workspaces) stays on your machine. No telemetry, no analytics, no cloud sync. Your API keys are stored locally and only sent to your chosen AI provider. For maximum privacy, use the Ollama provider to run models entirely locally.

Can I use multiple AI providers?

Yes. You can switch providers at any time from Settings. Your conversation history is preserved. Each provider has its own set of models — pick the one that works best for your task.

How do I get an API key?

The setup wizard includes direct links to each provider's API key page. Gemini offers a free tier at aistudio.google.com/apikey. Groq offers a free tier at console.groq.com/keys. For fully local AI, install Ollama from ollama.com — no API key needed.

How do I contribute?

JARVIS is open source and contributions are welcome. Read CONTRIBUTING.md for setup instructions, code style, and PR guidelines. Run ./scripts/doctor.sh to verify your development environment.
